## 목적과 관리 기준

Image AI Platform의 기능 범위를 대분류(업무 영역), 중분류(기능 묶음), 소분류(개별 기능)의 3단계로 정의합니다. 2026-11-10 사용자 승인으로 초안의 기능 목록을 확정했습니다.

소분류는 사용자가 수행하는 동작 단위이며, 기능 ID는 화면·API·권한·구현 단계 문서에서 참조할 식별자입니다. 확정 상태는 기능 범위의 확정을 의미하며 구현 완료를 의미하지 않습니다. 구현 상태와 검증 근거는 [개발 진척도 현황판](../plans/README.md#개발-진척도-현황판) 및 해당 단계 문서에서 관리합니다.

세부 정책 중 미정으로 표시된 항목은 별도 요구사항으로 구체화합니다. 기능 범위를 변경하면 이 문서를 함께 갱신하고, 중요한 설계 결정은 ADR에 기록합니다. 추가 기능 제안은 [agent의 제안](../agent-suggestions.md)에서 관리하며 승인 전에는 확정 기능에 포함하지 않습니다.

## 데이터셋 생성 화면

사용자 식별 변경(2026-11-10): 생성자·수정자는 서버에서 확인한 내부 user_key를 기록합니다. 로그인 아이디 user_id와 실제 이름 username은 구분하며 [ADR-031](../decisions/ADR-031-user-identity-fields.md)을 따릅니다.

현재 구현(2026-11-10): 활성 로그인 계정이 이름 필수·최대 200자, 설명 선택·최대 2000자로 생성할 수 있습니다. 이름 중복을 허용하며 서버에서 UUID, 날짜·시간을 포함한 생성/수정 타임스탬프와 로그인 작업자를 기록합니다. 생성 화면에 실제 저장을 연결했으며 상세 미구현으로 현재 성공 시 이름·ID를 표시하고 폼을 초기화합니다. 구체 계약은 [ADR-030](../decisions/ADR-030-dataset-creation-contract.md)과 [API](../api/api.md#데이터셋-생성)를 따릅니다. 아래 새 상세 이동은 후속 목표 흐름입니다.

데이터셋 생성(DATA-001)의 화면 방식은 2026-11-10 사용자 결정으로 독립 페이지로 확정했습니다. `데이터셋 > 데이터셋 생성` 메뉴를 기본 진입점으로 사용하며 목록의 생성 버튼도 같은 페이지로 연결합니다. 성공 시 새 상세로, 취소 시 미저장 상태로 목록에 이동합니다. 수정·삭제는 기존 모달 초안을 유지합니다. [ADR-029](../decisions/ADR-029-dataset-creation-page.md)와 [화면 설계](../storyboards/dataset-management/README.md)를 따르며 구체 URL·입력 제한·페이지 이탈 정책은 미정입니다.

## 상세 정의 작성 기준

각 소분류의 상세 요구사항은 사용자, 선행 조건, 입력, 기본 흐름, 결과, 예외, 완료 조건으로 구체화합니다. 다음 DATA-001 항목은 초안에서 제시한 상세 정의 예시이며, 미정 정책을 확정하는 근거로 사용하지 않습니다.

| 항목 | DATA-001 데이터셋 생성 |
|---|---|
| 사용자 | 데이터셋 생성 권한이 있는 사용자 |
| 선행 조건 | 로그인 완료 |
| 입력 | 이름, 설명 — 필수 여부와 길이 제한은 미정 |

| 결과 | 데이터셋이 생성되고 상세 정보를 조회할 수 있다. |
| 예외 | 필수값 누락, 입력 제한 위반, 권한 없음 |
| 완료 조건 | 생성한 데이터셋을 목록과 상세에서 확인할 수 있다. |

## 데이터셋 관리 확장 — 2026-11-13 확정·구현

이미지·데이터 파일은 모두 폴더 선택 업로드를 지원합니다. 선택한 폴더부터 하위 파일까지의 상대 경로를 원본 파일명에 저장하고 표시합니다. 같은 데이터셋·파일 유형에서 전체 경로를 중복·버전 교체 기준으로 사용합니다. 빈 폴더 자체는 관리하지 않습니다(ADR-046).

데이터셋 관리 화면은 이미지 파일과 데이터 파일 탭으로 나눕니다. 이미지 탭은 기존 썸네일·원본 상세를 유지합니다. 데이터 파일 탭은 이미지를 포함한 모든 형식의 원본 바이너리 보관·다운로드를 제공하며 썸네일을 관리하지 않습니다(ADR-044). 두 유형 모두 파일별 설명, 목록·버전·감사 정보, 신규/수정 업로드, 선택 삭제와 선택 설명 일괄 저장을 지원합니다. 데이터 파일의 내용 분석·파싱은 후속 범위입니다.

데이터 파일 기능 권한은 dataset:file:read, dataset:file:upload, dataset:file:update, dataset:file:delete로 이미지·데이터셋과 독립 관리합니다. 조회에는 활성 공간 멤버십, 쓰기에는 공간 운영자 또는 데이터셋 생성자 조건을 추가합니다. [API](../api/api.md#데이터-파일-api--2026-11-13)와 [화면 기준](../plans/front/design.md#데이터셋-관리와-파일-탭--2026-11-13)을 따릅니다.
