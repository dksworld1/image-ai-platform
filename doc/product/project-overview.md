# 프로젝트 개요

상태: 초안  
갱신일: 2026-11-01

## 목적

Image AI Platform은 이미지 데이터를 모으고 관리해 AI 활용에 필요한 데이터셋으로 준비할 수 있도록 지원하는 플랫폼을 지향합니다. 수집부터 정리·가공·레이블링·탐색까지 이어지는 작업 흐름을 제공하고, 사용자가 확장 가능한 이미지 처리 기능을 연결할 수 있게 하는 것이 목표입니다.

현재 저장소는 React + TypeScript 프런트엔드와 Spring Boot REST API의 기본 실행 골격을 제공합니다. 아래 기능은 제품 방향으로 정리한 예정 범위이며, 구현 상태나 확정된 세부 요구사항을 의미하지 않습니다.

## 주요 제공 기능

### 이미지 데이터 수집

다양한 입력 경로에서 이미지와 관련 메타데이터를 가져와 프로젝트 또는 데이터셋 단위로 관리합니다. 수집 경로, 지원 형식, 중복 판별, 메타데이터 범위는 별도 요구사항으로 구체화합니다.

### 이미지 업로드

사용자가 이미지 파일을 플랫폼에 등록하고 업로드 결과를 확인할 수 있도록 합니다. 대용량 업로드, 허용 형식과 크기, 실패 복구, 저장 위치 및 보존 정책은 저장소와 운영 환경 설계에서 결정합니다.

### 이미지 전처리

학습과 분석에 사용할 수 있도록 이미지 변환 및 정규화 작업을 지원합니다. 전처리 단계와 설정을 재현할 수 있도록 작업 이력과 적용 조건을 관리하는 방향을 검토합니다.

### 레이블링

이미지에 분류, 태그 또는 기타 레이블을 부여하고 검토·수정할 수 있도록 합니다. 레이블 체계와 검수 흐름은 사용 사례에 맞춰 확정합니다.

### 클러스터링

이미지의 유사도 또는 특징을 바탕으로 데이터 탐색과 정리를 돕는 그룹화 기능을 제공합니다. 사용 모델, 군집 기준, 결과 검토 방식은 별도 설계가 필요합니다.

### 사용자 플러그인 이미지 처리

사용자가 제공하거나 선택한 플러그인으로 이미지 처리 단계를 확장할 수 있도록 합니다. 플러그인 실행 경계, 입력·출력 계약, 권한, 격리, 자원 제한 및 오류 처리는 안전한 확장을 위해 별도 설계해야 합니다.

## 예상 작업 흐름

```text
이미지 수집·업로드
        ↓
데이터셋 구성 및 메타데이터 관리
        ↓
전처리·레이블링·플러그인 처리
        ↓
클러스터링과 결과 검토
        ↓
정리된 데이터셋 활용
```

각 단계는 데이터셋의 상태와 작업 이력을 추적할 수 있도록 연결하는 것을 목표로 합니다. 단계의 순서와 선택 가능 여부는 실제 사용자 흐름을 확인한 뒤 결정합니다.

## 설계 방향

- 이미지와 메타데이터의 수명 주기를 명확히 하고, 원본과 처리 결과를 구분합니다.
- 장시간 실행되는 전처리·플러그인·클러스터링 작업은 요청과 결과 조회를 분리하는 방식을 검토합니다.
- 사용자 작업 및 데이터 접근 권한을 고려해 데이터셋 경계를 설계합니다.
- 처리 설정과 결과를 연결해 재현 및 검토가 가능하도록 합니다.
- 플러그인은 명시된 입력·출력 계약과 제한된 실행 권한을 따르도록 설계합니다.
- 구체적인 기술 선택은 요구사항과 운영 제약을 확인한 뒤 ADR로 기록합니다.

## 이번 단계에서 정할 항목

- 주요 사용자와 대표 사용 사례
- 이미지 데이터의 출처, 지원 형식, 메타데이터 모델
- 업로드 방식, 저장소, 보존 및 삭제 정책
- 레이블 체계와 검수 권한
- 전처리 작업 정의와 결과 버전 관리
- 클러스터링 입력·출력 및 결과 탐색 방식
- 플러그인 배포·실행 모델과 보안 경계
- 사용자 인증, 데이터셋 권한, 작업 상태 및 오류 처리
