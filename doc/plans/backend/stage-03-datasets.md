# 3단계: 데이터셋과 메타데이터

- 상태: 구현 중 — 생성 API·화면 저장 연동 완료, 조회·소유·공유는 미구현
- 선행 단계: 1, 2단계
- 관련 문서: [제품 개요](../../product/project-overview.md), [API 계약](../../api/api.md)
- 관련 결정: [ADR-007 백엔드 모듈 경계](../../decisions/ADR-007-backend-modules.md)

사용자가 작업별로 지시할 개발 순서·상태·완료 기준은 [데이터셋 업무 개발 작업계획서](../dataset-development-plan.md)에서 관리합니다. 기능 범위는 [기능 정의서](../../product/functional-specification.md)의 DATA-001~009를 따릅니다. 화면은 [스토리보드 v1](../../storyboards/dataset-management/README.md) 초안이며 세부 입력·소유·공유·삭제 정책은 아직 미정입니다. 신규 테이블은 [공통 스키마 규칙](../../db-schema/schema-rules.md)과 시스템 ID `'0'`을 적용합니다.

## 목표

이미지와 처리 결과를 묶고 관리하는 데이터셋 경계를 정의합니다.

## 핵심 개념과 원리

- 데이터셋은 이미지 항목, 메타데이터, 레이블 및 작업 결과를 연결하는 관리 단위입니다.
- 메타데이터는 파일 자체의 속성과 사용자가 관리하는 설명 정보를 구분합니다.
- 원본과 파생 산출물의 관계를 추적해 처리 이력과 재현성을 보존합니다.
- 데이터셋 접근은 1단계의 인증·권한 판단을 따릅니다.

## 설계 범위

데이터셋 소유권, 항목 식별자, 메타데이터 스키마, 상태 및 버전, 삭제·보존 정책을 정의합니다.

데이터셋·이미지 메타데이터 기능은 `com.imageaiplatform.dataset` 모듈이 소유합니다. 인증·권한이 필요한 작업은 `auth` 모듈의 서비스 경계를 통해 판정하며, 모듈 간 DAO 직접 호출은 하지 않습니다.

## 결정 기록

- 구현(2026-11-10): POST /api/datasets와 app V6를 추가했습니다. 활성 로그인 사용자 생성, UUID 발급, 이름 필수·설명 선택, 서버 타임스탬프·작업자 기록은 [ADR-030](../../decisions/ADR-030-dataset-creation-contract.md)을 따릅니다. 데이터 계약은 [dataset 정의서](../../db-schema/tables/dataset/dataset.md), HTTP 계약은 [API 문서](../../api/api.md#데이터셋-생성)에서 관리합니다.

- 확정(2026-11-10): 생성은 독립 페이지이며 메뉴는 `데이터셋 > 데이터셋 생성`으로 관리합니다. [ADR-029](../../decisions/ADR-029-dataset-creation-page.md). 입력·소유·공유·API 정책은 여전히 미정입니다.

- 미결정: 데이터셋 공유 및 협업 단위
- 미결정: 메타데이터 필수 필드와 확장 필드 방식
- 미결정: 변경 이력 및 버전 관리 수준

## 완료 조건

생성 기능 검증: Java 21.0.13·Maven 3.10.0에서 전체 테스트 57개 통과. 신규 생성 테스트 5개로 실제 DB 저장, 요청 감사 정보 무시, 서버 UUID·동일 생성/수정 시각·로그인 작업자, 빈 설명·중복 이름, 입력 오류·비인증·비활성·삭제 계정, 직접 서비스 권한 경계를 확인했습니다. 실제 로컬·운영 DB에는 적용하지 않았으며 생성 이외 아래 단계 전체 완료를 뜻하지 않습니다.

최종 V6에 시스템 INSERT용 공통 기본값을 맞춘 뒤 DatasetCreationTest·DatabaseMigrationTest 6개를 재실행해 통과했습니다. 두 실행 모두 기본 app·audit·catalog·archive URL을 별도 메모리 DB로 지정하고 각 테스트의 격리 DB를 사용했습니다.

- 데이터셋과 이미지 항목의 관계 및 소유권이 정의되어 있습니다.
- 원본·파생 데이터와 메타데이터의 수명 주기가 정리되어 있습니다.
- 삭제·보존 및 접근 제어 원칙이 정의되어 있습니다.
