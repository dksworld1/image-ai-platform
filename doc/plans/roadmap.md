# 개발 계획

상태: 제품 단계 설계 중
갱신일: 2026-11-01

## 현재 기준선

- React + TypeScript + Vite 프런트엔드 골격
- Spring Boot REST API 및 헬스체크
- 개발 프록시와 CORS 기본 설정
- 제품 개요와 단계별 기능 설계 문서

위 항목 중 마지막 항목은 문서화 상태를 말하며 제품 기능 구현 완료를 뜻하지 않습니다.

## 제안 구현 순서

단계별 목표·개념·결정·완료 조건은 [기능 구현 단계](../stages/README.md)에서 관리합니다.

1. 백엔드 프레임워크와 데이터 기반
2. 인증과 권한
3. 데이터셋과 메타데이터
4. 이미지 수집과 업로드
5. 전처리
6. 레이블링
7. 클러스터링
8. 사용자 플러그인 이미지 처리

## 후속 설계 우선 항목

- 사용자와 대표 작업 흐름 구체화
- 이미지 저장소, 업로드 제한, 보존·삭제 정책
- 장시간 작업의 상태·실패·재시도 모델
- 레이블 체계와 검수 흐름
- 플러그인 신뢰 경계와 격리 방식
- 운영 배포, 관측성, 비용 및 보안 요구사항
