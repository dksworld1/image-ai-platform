# 지원 포트폴리오 기록

이 폴더는 SK Careers 공고 [전사 통합 Image 솔루션 제공 플랫폼 Application 개발·운영 PL](https://www.skcareers.com/Recruit/Detail/R261970) 지원을 위해 이 저장소의 작업과 그 근거를 정리하는 공간입니다.

## 사용 방법

사용자가 문서화를 지시하면 저장소의 현재 코드, 설계 문서, ADR, 단계 기록과 확인 가능한 검증 결과를 검토해 포트폴리오 자료를 갱신합니다. 구현 진행 중에는 요청이 없어도 공고와의 연결성이 높은 어필 요소와 보완점을 제안할 수 있습니다. 개인 경력이나 성과는 사용자가 제공하거나 저장소에서 사실로 확인되는 내용만 사용하고, 확인되지 않은 주장은 질문 또는 미확인 항목으로 남깁니다.

## 문서

- [공고 적합도 및 프로젝트 어필 전략](fit-and-project-strategy.md): 공고 요구사항, 저장소 근거, 객관적 강점·갭, 프로젝트 개선 제안

## 기록 원칙

- 프로젝트에서 실제 구현한 것, 설계한 것, 검증한 것을 구분합니다.
- 검증은 실행 명령과 결과를 확인한 경우에만 완료로 표시합니다.
- 공고에 직접 연결되는 결과는 문제·선택·구현·검증·효과의 흐름으로 정리합니다.
- 개인의 연차, 운영 이력, 리딩 경험 등 저장소만으로 알 수 없는 사항은 추정하지 않습니다.
- 이력서·자기소개서용 문구는 근거 링크와 함께 초안으로 기록하며, 사실 확인 전 성과 수치를 만들지 않습니다.
