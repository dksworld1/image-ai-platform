# 테이블 정의서

테이블 정의는 기능별 하위 폴더에서 관리합니다. DB 테이블을 추가·변경·삭제하면 같은 변경에서 해당 정의서를 갱신하고, 새 테이블이면 업무 그룹에 맞는 문서를 추가합니다.

## 그룹

- [인증](auth/): 사용자 인증 정보
- [기반](foundation/): 기반 동작 확인용 테이블

## 데이터베이스

새 업무 기능은 `app` 데이터소스를 사용합니다. app 테이블은 그룹별 정의서와 `backend/src/main/resources/db/migration/`의 Flyway 버전 SQL로 함께 관리합니다. legacy `catalog` 및 `archive` 데이터소스는 기존 기반 코드 호환을 위해 남아 있으며, 신규 업무 마이그레이션 대상이 아닙니다.
