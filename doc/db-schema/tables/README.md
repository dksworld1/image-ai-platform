# 테이블 정의서

테이블 정의는 기능별 하위 폴더에서 관리합니다. DB 테이블을 추가·변경·삭제하면 같은 변경에서 해당 정의서를 갱신하고, 새 테이블이면 업무 그룹에 맞는 문서를 추가합니다.

## 그룹

모든 현재 프로젝트 테이블은 [공통 스키마 생성 규칙](../schema-rules.md)을 따릅니다. 생성일·수정일·생성자·수정자를 필수로 두고 시스템 작업자 ID는 문자열 `'0'`을 사용합니다. app 기존 테이블에는 V5에서 적용하며 폐기된 UI 구조는 과거 이력으로 보존합니다.

- [인증·권한](auth/README.md): 기존 사용자 인증 정보 및 신규 RBAC 테이블 설계 초안
- [데이터셋](dataset/README.md): 데이터셋 기본 정보, 이미지 버전과 생성·수정·삭제 이력
- [워크스페이스](workspace/README.md): V10 공간·멤버십과 데이터셋 nullable 공간 FK, local 초기 데이터. 업무 API·실제 DB 미적용
- [기반](foundation): 기반 동작 확인용 테이블

## 폐기 이력

- [화면·메뉴 모듈](../../archive/ui/README.md): V4에서 제거한 테이블 정의와 API·화면 설계 이력

## 데이터베이스

새 업무 기능은 `app` 데이터소스를 사용합니다.

설계 단계의 테이블도 정의서로 먼저 관리할 수 있습니다. 이 경우 미구현·DB 미적용 상태을 명시하고, 실제 SQL 적용 상태와 구분합니다.
