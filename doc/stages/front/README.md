# 프런트 단계 설계 문서

- 상태: 설계 중
- 갱신일: 2026-11-08
- 전체 진척: [개발 진척도 현황판](../README.md)

프런트 관련 설계 문서는 `doc/stages/front/`에서 관리합니다. 전체 진척도에서는 프런트를 하나의 단계로 집계하고, 세부 설계와 완료 조건은 아래 문서에서 관리합니다.

## 문서 목록

| 문서 | 내용 | 상태 |
|---|---|---|
| [화면과 사용자 흐름 설계](design.md) | 현재 구현, 화면 흐름, 코드 구성, API·인증·오류 처리, 완료 조건 | 설계 중 |

## 관리 원칙

- 공통 설계는 현재 설계 문서에서 관리하고, 주제별 상세 설계가 필요해지면 이 디렉터리에 문서를 추가하고 목록에 연결합니다.
- 업무 규칙과 API 계약은 해당 기능 단계 및 기준 문서를 참조하며 중복 정의하지 않습니다.
- 미결정 사항과 채택한 결정을 구분하고 중요한 구조·의존성 결정은 `doc/decisions/`의 ADR과 연결합니다.
- 문서 추가 자체는 기능 구현이나 의존성 도입 승인을 의미하지 않습니다.
