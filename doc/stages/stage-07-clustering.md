# 7단계: 클러스터링

- 상태: 계획
- 선행 단계: 1, 3, 4단계, 필요 시 5단계
- 관련 문서: [제품 개요](../product/project-overview.md)

## 목표

이미지 간 유사도와 특징을 바탕으로 데이터 탐색 및 정리를 지원합니다.

## 핵심 개념과 원리

- 클러스터는 선택한 입력 집합, 특징 표현, 알고리즘과 설정에 종속된 결과입니다.
- 결과에는 사용한 입력과 설정을 연결해 반복 실행 간 비교 가능성을 둡니다.
- 군집 결과는 탐색을 돕는 분석 결과이며, 사용자가 검토하고 해석할 수 있어야 합니다.
- 대규모 연산은 비동기 작업 및 진행 상태 추적을 필요로 할 수 있습니다.

## 설계 범위

특징 추출, 거리·군집 기준, 결과 시각화와 검토, 재실행 및 규모 제약을 정의합니다.

## 결정 기록

- 미결정: 클러스터링 대상과 기본 특징 추출 방식
- 미결정: 알고리즘·설정 노출 수준
- 미결정: 결과를 데이터셋에 반영하는 방식

## 완료 조건

- 입력 집합과 실행 설정을 결과에 연결할 수 있습니다.
- 결과 탐색·검토 방식과 작업 실패 처리가 정의되어 있습니다.
- 사용자에게 결과 해석의 한계와 설정을 전달할 수 있습니다.
