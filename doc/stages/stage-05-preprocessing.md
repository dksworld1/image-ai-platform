# 5단계: 이미지 전처리

- 상태: 계획
- 선행 단계: 1, 3, 4단계
- 관련 문서: [제품 개요](../product/project-overview.md), [아키텍처](../architecture/architecture.md)

## 목표

데이터셋 이미지를 분석·학습에 적합한 형태로 변환하고 결과를 추적합니다.

## 핵심 개념과 원리

- 전처리는 원본을 덮어쓰지 않고 입력과 파생 결과의 관계를 보존해야 합니다.
- 설정, 처리기 버전, 입력 식별자와 결과를 연결하면 재현과 비교가 가능합니다.
- 이미지 작업은 실패·취소·재시도를 고려한 상태를 가져야 합니다.
- 변환은 명시적인 입력·출력 계약과 자원 제한을 따라야 합니다.

## 설계 범위

변환 단계, 배치 처리, 작업 상태, 산출물 버전, 자원 한도 및 오류 복구를 정의합니다.

## 결정 기록

- 미결정: 기본 변환 연산과 사용자 설정 범위
- 미결정: 작업 실행 및 큐잉 방식
- 미결정: 결과 버전·캐시 정책

## 완료 조건

- 원본 보존과 파생 결과 추적이 보장됩니다.
- 작업 상태와 실패·취소·재시도 규칙이 정의되어 있습니다.
- 설정과 처리 결과를 연결할 수 있습니다.
