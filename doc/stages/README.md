# 기능 구현 단계

상태: 제안된 제품 구현 순서  
갱신일: 2026-11-07

이 문서는 이미지 데이터 플랫폼의 기능을 의존 관계에 따라 나누어 추적합니다. 순서는 현재의 설계 제안이며 확정 아키텍처나 구현 완료를 뜻하지 않습니다. 각 단계에서 내린 결정과 핵심 개념·원리, 완료 조건을 해당 단계 문서에 누적합니다.

## 최우선 개발 항목

다음 백엔드 개발은 [애플리케이션 설정 모듈](stage-application-settings.md)을 최우선으로 진행합니다. 기존 단계 번호는 유지하고, 남은 인증·권한 및 제품 기능 개발에 앞서 설정 모듈의 범위를 정의하고 구현합니다.

| 단계 | 주제 | 선행 관계 | 상태 |
|---|---|---|---|

단계 간 세부 의존성은 사용자 흐름과 기술 검토 결과에 따라 조정할 수 있습니다. 전처리, 레이블링, 클러스터링은 공통 데이터 기반이 마련된 뒤 병렬 설계가 가능할 수 있습니다.

## 단계별 기록 항목

- 목표와 사용자 가치
- 범위 및 제외 범위
- 선행 조건과 다른 단계에 미치는 영향
- 핵심 개념 및 동작 원리
- 데이터·API·권한·오류 처리 원칙
- 결정 기록: 상태, 선택, 근거, 영향, 관련 ADR
- 미결정 질문과 후속 조치
- 완료 조건과 실제 검증 결과

단계 문서의 공통 틀은 [단계 기록 서식](../templates/stage-record.md)을 따릅니다.

결정이 확정되기 전에는 선택지를 사실로 기술하지 않습니다. 구현 완료 상태는 코드와 검증을 확인한 뒤에만 갱신합니다.
