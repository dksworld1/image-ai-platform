**2026-11-08 기준 · 전체 10개 기능 · 완료 1 · 진행 중 3 · 계획 6 · 보류 0**

기능 수 기준 완료율은 **1/10(10%)**입니다. 각 기능을 한 건으로 집계하며 개발 공수는 가중하지 않습니다. 진행 중에는 설계 중도 포함합니다. 하위 작업의 보류 여부는 해당 기능 행에 표시합니다.

단계 간 세부 의존성은 사용자 흐름과 기술 검토 결과에 따라 조정할 수 있습니다. 전처리, 레이블링, 클러스터링은 공통 데이터 기반이 마련된 뒤 병렬 설계가 가능할 수 있습니다.

## 단계별 기록 항목

- 목표와 사용자 가치
- 범위 및 제외 범위
- 선행 조건과 다른 단계에 미치는 영향
- 핵심 개념 및 동작 원리
- 데이터·API·권한·오류 처리 원칙
- 결정 기록: 상태, 선택, 근거, 영향, 관련 ADR
- 미결정 질문과 후속 조치
- 완료 조건과 실제 검증 결과

단계 문서의 공통 틀은 [단계 기록 서식](../templates/stage-record.md)을 따릅니다.

결정이 확정되기 전에는 선택지를 사실로 기술하지 않습니다. 구현 완료 상태는 코드와 검증을 확인한 뒤에만 갱신합니다.

기능 상태나 완료 조건이 바뀌면 같은 변경에서 해당 행과 기준일을 갱신합니다. 상위 기능의 상태가 바뀌면 전체 집계도 갱신합니다.
