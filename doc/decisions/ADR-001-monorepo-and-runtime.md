# ADR-001: 프런트엔드와 백엔드를 단일 저장소로 구성

- 상태: 채택
- 날짜: 2026-11-01

## 맥락

프로젝트 도메인 요구가 아직 구체화되지 않은 초기 단계다. 웹과 API를 빠르게 함께 변경할 수 있고 역할 경계를 명확히 유지할 구성이 필요하다.

## 결정

`frontend/`에는 React, TypeScript, Vite를 두고 `backend/`에는 Java 21과 Spring Boot MVC API를 둔다. 각 앱은 자체 개발 명령과 빌드 생명주기를 가진다. 로컬 개발에서는 Vite가 `/api` 요청을 백엔드로 프록시한다.

## 결과

- 한 변경에서 API와 화면을 함께 추적하기 쉽다.
- 빌드와 의존성은 앱별로 독립적이다.
- 각 구성 요소의 경계가 커지면 별도 배포 단위나 저장소 분리를 재검토한다.
- 운영 배포와 데이터 저장소는 제품 요구 확정 후 결정한다.
