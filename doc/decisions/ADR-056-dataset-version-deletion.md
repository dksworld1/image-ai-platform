# ADR-056: 편집본과 영구 버전 삭제

- 상태: 채택
- 날짜: 2026-11-25
- 관련 결정: [ADR-052](ADR-052-dataset-version-snapshots.md), [ADR-055](ADR-055-independent-dataset-version-drafts.md)

## 맥락

버전 목록에서 편집본과 영구 버전을 각각 삭제할 수 있어야 합니다. 기준 영구 버전을 삭제하더라도 그 버전에서 시작한 편집본을 계속 사용할 수 있어야 합니다.

## 대안

- 영구 버전 행을 물리 삭제하면 편집본의 기준 버전 참조와 버전 번호 이력을 재설계해야 합니다.
- 영구 버전에 삭제 표시를 하면 공개 목록과 상세에서 제외하면서 참조와 번호 이력을 보존할 수 있습니다.

## 결정

편집본 삭제는 선택한 편집본 항목만 제거합니다. 영구 버전은 삭제 표시를 적용해 공개 조회와 다운로드에서 제외합니다. 기존 편집본은 작업용 파일 구성과 기준 버전 번호를 유지하며 계속 편집하고 확정할 수 있습니다.

## 결과

두 삭제 모두 기존 데이터셋 삭제 권한과 관리 범위를 검사합니다. 원본 바이트와 확정 스냅샷은 보존하며 영구 버전 번호는 계속 증가합니다.
