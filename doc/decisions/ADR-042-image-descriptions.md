# ADR-042: 이미지별 설명과 선택 변경 행 일괄 저장

- 상태: 채택
- 날짜: 2026-11-13
- 대체/관련 기록: ADR-039·040·041 확장

## 맥락

사용자는 업로드 시 파일별 설명 입력, 이미지 목록의 설명 편집과 변경 강조·자동 선택, 선택한 변경 행 일괄 저장을 요청했습니다. 저장 확인창은 미선택된 변경 행의 건수와 초기화 안내만 표시하도록 후속 지시했습니다.

## 대안

- 행별 즉시 저장: 선택 행을 모아 확인 후 저장하는 요구와 다릅니다.
- 프런트 임시 편집과 단일 트랜잭션 저장: 변경/선택 상태를 따로 유지하고 확인한 대상만 원자적으로 반영할 수 있습니다.

## 결정

설명은 이미지 버전 행의 선택 입력으로 최대 2,000자이며 빈 값·공백만 있는 값은 NULL입니다. 업로드 모달에서 파일별로 입력하고 신규/수정 업로드 모두 해당 파일의 설명을 저장합니다. 새 버전의 설명은 업로드 입력값을 사용하며 과거 버전·이력의 설명은 보존합니다.

설명만 편집하면 기존 활성 이미지 행의 설명·수정 감사 값만 갱신하고 UPDATE 이력에 설명 스냅샷을 남깁니다. 이미지 ID·파일·버전 번호·생성 감사 정보는 바꾸지 않습니다. 기존 image:update와 대상 조건을 적용합니다.

프런트는 원본 목록과 임시 설명을 분리해 실제 변경 행을 강조하고 자동 선택합니다. 체크를 해제해도 편집 내용과 강조는 저장 전까지 유지합니다. 저장 대상은 선택된 행 중 실제 설명이 달라진 행뿐입니다. 확인창에는 미선택된 변경 행이 있을 때 그 건수와 저장 후 편집 내용 초기화를 알리고, 없으면 일반 저장 확인만 표시합니다. 선택된 저장 대상 수는 확인창에 표시하지 않습니다.

한 PATCH 요청·app 트랜잭션으로 대상 변경과 이력을 모두 저장합니다. 한 행의 권한·상태·검증·이력 저장이 실패해도 전체 롤백합니다. 성공 시 선택한 수정은 반영하고 미선택된 편집은 원본으로 되돌립니다. 실패·확인 취소 시 편집과 선택을 보존합니다. 변경 행을 모두 해제한 상태에서 저장을 확인하면 서버 요청 없이 편집만 초기화합니다.

## 결과

V22는 이미지와 이력에 nullable description 컬럼을 추가하며 기존 설명은 NULL입니다. 기존 SQL·이력은 수정하지 않습니다. 프런트의 편집 내용은 새로고침·대상 전환 후 보존하지 않습니다. 자동 재시도하지 않으며 통신 단절의 결과는 목록 재조회로 확인합니다. 설명 편집을 위한 새 파일 버전·권한·공통 편집 프레임워크는 추가하지 않습니다.
