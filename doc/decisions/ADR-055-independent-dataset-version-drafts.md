# ADR-055: 독립 데이터셋 버전 편집본과 상세 주소

- 상태: 채택
- 날짜: 2026-11-25
- 대체 기록: [ADR-054](ADR-054-persist-dataset-version-draft.md)의 단일 공유 편집본 정책

## 맥락

여러 기준 버전에서 시작한 작업을 동시에 보존해야 합니다. 버전 상세도 주소로 다시 열고 브라우저 뒤로가기로 목록에 돌아갈 수 있어야 합니다.

## 대안

- 공유 편집본에 이름만 추가하면 동시에 한 작업만 유지됩니다.
- 독립 작업용 데이터셋에 구성 행을 두면 기존 이미지·파일 API를 재사용하면서 파일 바이트는 공유할 수 있습니다.

## 결정

새 편집본은 고유 ID, 이름, 기준 버전 ID와 독립된 작업용 데이터셋을 갖습니다. 원본 파일의 저장 경로는 재사용하고 파일 설명과 활성 목록은 편집본마다 보관합니다. 확정하면 선택한 편집본만 목록에서 제거하고 해당 작업용 파일에 대한 직접 편집 접근을 닫습니다.

상세는 `versionId`, 편집은 `versionId`와 `draftId`를 쿼리에 기록합니다. 버전 목록에서 상세로 이동할 때 브라우저 이력에 추가합니다.

## 결과

이관한 기존 공유 편집본 한 건은 기존 파일 구성을 유지합니다. 새 편집본에는 독립 작업용 데이터셋을 사용합니다. [API](../api/api.md#데이터셋-버전-편집본) · [테이블 정의](../db-schema/tables/dataset/dataset-version.md#dataset_version_draft)
