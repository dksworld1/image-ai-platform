# ADR-015 외부 YAML 실행 옵션과 환경 변수 사용 금지

- 상태: 채택
- 날짜: 2026-11-07
- 관련 기록: ADR-004, ADR-009, ADR-013의 환경 변수 전달 방식을 대체합니다.

## 맥락

기존 dev/prod 실행에는 외부 JDBC YAML 경로를 전달하는 사용자 정의 키가 필요했습니다.

## 대안

사용자 정의 키를 유지하거나 Spring 표준 실행 옵션으로 서버의 파일을 지정할 수 있습니다.

## 결정

프로젝트 코드와 실행 스크립트에서 환경 변수 사용을 금지합니다. DB 접속 정보와 JWT 키는 서버의 외부 YAML에 보관하고 JAR 실행 시 `--spring.config.additional-location`으로 지정합니다.

## 결과

기존 배포의 환경 변수 값은 전환 전에 YAML에 옮깁니다. 프런트엔드는 상대 경로 `/api`를 사용하며 로컬 실행 스크립트는 포트를 실행 인자로 전달합니다. Spring과 빌드 도구 자체의 표준 환경 처리 기능은 이 결정의 적용 범위 밖입니다. 실행 예시는 [배포 문서](../operations/deployment.md)에 기록합니다.
