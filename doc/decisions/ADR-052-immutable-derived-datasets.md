# ADR-052: 불변 데이터셋과 파생 저장

- 상태: 채택 · 구현 예정
- 날짜: 2026-11-22
- 관련 기록: [ADR-035](ADR-035-dataset-deletion-authorization.md), [ADR-039](ADR-039-image-version-history.md), [ADR-049](ADR-049-artifact-file-unification.md)

## 맥락

학습 입력을 재현하려면 데이터셋 ID가 가리키는 구성과 파일 내용이 저장 이후 고정돼야 합니다. 사용자는 기존 구성을 바탕으로 파일을 추가·교체·제외할 수 있어야 합니다.

## 대안

- 편집 가능한 데이터셋과 별도 발행 버전을 두면 현재 편집을 계속할 수 있습니다. 실행에는 별도의 버전 ID 선택이 필요합니다.
- 데이터셋을 불변으로 저장하고 변경은 파생본으로 저장하면 데이터셋 ID로 입력이 고정되고 같은 부모에서 독립된 자식을 만들 수 있습니다.

## 결정

저장된 데이터셋의 메타데이터와 파일 구성을 변경할 수 없게 합니다. 기존 데이터셋을 상속해 만든 작업본을 저장할 때는 새 데이터셋 ID와 직접 부모 데이터셋 ID를 기록합니다. 처음 저장하는 데이터셋의 부모 ID는 NULL입니다.

## 결과

기존 데이터셋의 직접 수정과 파일 변경 경로는 전환 시 파생 저장 흐름으로 대체합니다. 기존 데이터셋 전환, 파일 공유, 스테이지 입출력 연동의 세부 방식은 [불변 데이터셋과 파생 저장 설계](../plans/backend/dataset-version-design.md)에서 검토합니다.
