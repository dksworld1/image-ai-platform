# ADR-038: 업로드 시 썸네일 동기 생성과 권한 조회

- 상태: 채택
- 날짜: 2026-11-13
- 대체/관련 기록: ADR-036 확장, ADR-037

## 맥락

이미지 목록의 미리보기에 원본 전체를 전송하지 않도록 별도 썸네일이 필요합니다. 이번 범위는 백엔드이며 기존 로컬 파일 저장 방식을 유지합니다.

## 대안

- 조회 시 생성: 업로드 비용은 줄지만 최초 조회 지연과 생성 동시성 처리가 필요합니다.
- 업로드 시 동기 생성: 업로드 비용이 늘지만 성공 시 썸네일도 준비되어 있습니다.
- 비동기 생성: 상태·작업 큐 관리가 추가로 필요합니다.

## 결정

업로드 시 기본 긴 변 256px, 비율 유지·확대 금지로 PNG 썸네일을 생성합니다. 원본 바이트는 보존하고 GIF는 첫 프레임만 미리보기로 사용합니다. 기존 Java ImageIO로 구현하며 새 의존성은 추가하지 않습니다. 경로는 DB에 저장하고 조회 API에서 기존 데이터셋 읽기 권한과 공간 범위를 검사합니다. 파일 저장·DB 등록 실패 시 작성 파일을 롤백 정리합니다.

## 결과

업로드 CPU·저장 공간 비용이 증가합니다. 파일 시스템과 DB는 분산 트랜잭션이 아니므로 프로세스 중단·정리 실패 시 남은 파일은 후속 정리 대상입니다. 기존 이미지의 썸네일 소급 생성과 프런트 구현은 포함하지 않습니다. 상세는 [API](../api/api.md#데이터셋-이미지-업로드), [테이블](../db-schema/tables/dataset/dataset-image.md), [운영](../operations/deployment.md)을 따릅니다.
