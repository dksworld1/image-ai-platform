# ADR-045: 데이터 파일 저장명에 원본 확장자 보존

- 상태: 채택
- 날짜: 2026-11-13
- 대체/관련 기록: ADR-043·044의 파일 저장명 정책 보완

## 맥락

사용자는 원본 바이너리 파일을 UUID.bin 대신 UUID와 원본 확장자로 저장하도록 요청했습니다.

## 대안

- UUID.bin 고정: 저장 방식은 단순하지만 디스크에서 확장자를 알 수 없습니다.
- UUID + 원본 확장자: 충돌을 피하면서 원본 확장자를 보존합니다.

## 결정

새 데이터 파일 업로드·교체부터 마지막 점 이후 확장자를 대소문자 그대로 보존합니다. archive.tar.gz는 UUID.gz, 확장자가 없거나 .hidden처럼 선두 점만 있거나 마지막이 점이면 확장자 없이 UUID로 저장합니다. 확장자는 내용 검증·실행·썸네일 생성에 사용하지 않습니다.

## 결과

기존 .bin 파일은 DB 저장 경로로 계속 읽으며 이동하지 않습니다. 다운로드 원본명·바이트·권한·버전 정책은 유지합니다. 최대 255자 원본명의 긴 확장자도 수용하도록 V24에서 파일·이력 storage_path 길이를 100에서 300으로 확장합니다. API 필드와 프런트 변경은 없습니다.
