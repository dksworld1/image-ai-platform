# ADR-025: 탭 세션 복원과 헤더 계정 표시

2026-11-10: 사용자 세션 필드와 헤더 표시 정보는 [ADR-031](ADR-031-user-identity-fields.md)이 부분 대체합니다. 탭별 보관·만료·로그아웃 정책은 유지합니다.

- 상태: 채택
- 날짜: 2026-11-08
- 대체/관련 기록: [ADR-020](ADR-020-login-entry-memory-token.md)의 메모리 전용 보관과 매 진입 로그인 정책을 대체

## 맥락

사용자는 새로고침 후 토큰 재사용, 로그아웃 클릭 시 제거, 로그인 상태에서 헤더 우상단 사용자 정보 표시를 요청했습니다. 현재 토큰 응답에는 사용자 상세 정보가 없고 프로필 조회 API도 없습니다.

## 대안

- 메모리 전용: 새로고침 시 로그인 상태가 사라집니다.
- sessionStorage: 같은 탭의 새로고침에서 복원할 수 있습니다.
- localStorage: 브라우저를 다시 여는 경우까지 유지하는 별도 정책이 필요합니다.

## 결정

`sessionStorage`의 `image-ai-platform.auth`에 accessToken·tokenType·expiresIn·expiresAt·username을 저장합니다. 만료 시각은 로그인 응답 수신 시점과 expiresIn으로 계산하며 새로고침에서 갱신하지 않습니다. 비밀번호는 저장하지 않습니다. App 초기 진입 시 유효한 세션을 복원하고 만료·손상된 저장값은 제거합니다. 열린 화면에서도 만료 시각에 세션을 해제합니다.

헤더 우상단에는 로그인 요청에 사용한 아이디와 로그아웃 버튼을 표시합니다. 사용자명은 표시용이며 서버 인증 주체나 권한 판정에 사용하지 않습니다. 서버는 기존 Bearer 토큰으로 인증합니다. 이름·이메일·역할은 조회 계약이 없으므로 표시하지 않습니다.

## 결과

같은 탭에서 새로고침해도 로그인 상태와 계정 표시를 복원합니다. 유효한 세션이 없으면 로그인 화면을 표시합니다. 탭을 닫으면 일반적인 sessionStorage 수명에 따라 세션이 종료됩니다. 브라우저 세션 복원·탭 복제 동작은 브라우저 정책을 따르며 만료 검사를 유지합니다.

로그아웃은 저장값과 React 상태를 제거하고 로그인 화면으로 돌아갑니다. 기존 JWT를 서버에서 폐기하거나 refresh token을 발급하는 API는 추가하지 않습니다. 라우터나 신규 의존성을 도입하지 않습니다. 실제 서버가 거부한 토큰은 내비게이션 오류 안내와 로그아웃 후 재로그인으로 처리합니다.
