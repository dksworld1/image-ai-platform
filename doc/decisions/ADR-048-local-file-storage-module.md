# ADR-048: 아티팩트의 로컬 파일 스토리지 분리

- 상태: 부분 대체 — 인터페이스와 설정 해석 위치는 [ADR-050](ADR-050-artifact-storage-interface.md)을 따릅니다.
- 날짜: 2026-11-21
- 관련 기록: [ADR-047](ADR-047-artifacts-and-versioned-sets.md)

## 맥락

아티팩트 파일의 저장과 검증을 독립 스토리지 모듈에서 제공해야 합니다. 기존 파일의 루트 키와 상대 경로는 계속 사용해야 합니다.

## 대안

- 아티팩트 내부에 파일 입출력을 유지하면 변경 범위가 작지만 스토리지 로직이 업무 모델에 결합됩니다.
- 로컬 파일 입출력과 검증값 계산을 별도 모듈에 두면 아티팩트 설정과 상태 규칙을 기존 경계에 유지할 수 있습니다.

## 결정

`storage.domain.LocalFileStorage`가 로컬 파일의 쓰기·읽기·실측·삭제와 SHA-256 계산을 담당합니다. 아티팩트 모듈은 루트 키 해석, 업로드 한도, 확정 시 메타데이터 비교와 DB 롤백 보상을 담당합니다. 기록 중 실패한 파일은 쓰기 작업에서 삭제합니다.

## 결과

기존 API, 스키마, 저장 형식, 설정 키를 그대로 사용합니다. 현재 연결 대상은 아티팩트입니다.
