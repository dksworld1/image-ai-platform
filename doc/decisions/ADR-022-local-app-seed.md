# ADR-022: 로컬 app 관리자·메뉴 초기 데이터

- 상태: 채택
- 날짜: 2026-11-08
- 관련 기록: [ADR-018](ADR-018-per-datasource-migrations.md), [DB 마이그레이션 설정](../operations/database-migration.md)

## 맥락

시작 화면과 관리 화면·메뉴 정보, 로컬 admin 계정과 모든 기존 권한 연결을 마이그레이션 SQL로 재현해야 합니다.

## 대안

- 공통 버전 SQL: 모든 환경에 로컬 개발 계정이 들어가므로 사용하지 않습니다.
- local 전용 반복 SQL: 기존 스키마 이후 실행하고 체크섬 변경 시 초기 데이터를 다시 맞출 수 있습니다.

## 결정

local의 app 위치에만 `db/seed/local/app`을 추가하고 `R__local_app_seed.sql`을 적용합니다. `admin` 계정은 로컬 전용 BCrypt 해시와 활성 상태로, 소문자 `admin` 역할은 현재 정의된 전체 권한과 연결합니다. 화면·메뉴 코드는 시작 화면과 기존 화면·메뉴 관리 API 범위로 한정합니다. 사용자 요청에 따른 비운영 전용 고정 계정이며 실제 운영 비밀값은 포함하지 않습니다.

## 결과

새 local DB와 기존 V3 DB에 같은 SQL을 적용할 수 있습니다. 재실행은 seed 소유 값들을 초기값으로 맞추고 다른 데이터를 삭제하지 않습니다. Flyway는 체크섬이 같으면 실행을 생략하므로 미래 권한의 자동 부여를 보장하지 않습니다. 추가 권한은 후속 마이그레이션이나 seed 변경으로 연결합니다. H2 로컬 SQL이며 운영용 seed로 사용하지 않습니다. 화면 메타데이터 등록과 React 화면 구현은 구분합니다.
