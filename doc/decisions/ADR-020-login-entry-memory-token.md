# ADR-020: 임시 로그인 진입 화면과 메모리 토큰 보관

- 상태: 채택
- 날짜: 2026-11-08
- 관련 기록: [프런트 인증 단계](../stages/front/stage-02-authentication.md)

## 맥락

메뉴·화면 서비스의 UI 연동에 앞서 로그인 화면이 필요하며, 당분간 인덱스에 진입하면 로그인 화면을 먼저 표시하도록 요청되었습니다. refresh token은 제공하지 않습니다.

## 대안

- 메모리 보관: 새로고침 시 재로그인이 필요하지만 현재 최초 로그인 표시 요구에 맞고 영속 저장이 필요하지 않습니다.
- 브라우저 영속 저장: 재진입 시 로그인 유지 정책과 토큰 보관 정책을 추가로 확정해야 합니다.

## 결정

인덱스의 초기 React 상태는 미인증으로 시작합니다. 로그인 성공 응답의 access token은 `App` 상태에만 보관하고 기존 시작 화면으로 전환합니다. 비밀번호와 토큰은 브라우저 저장소에 기록하지 않습니다. 새로고침하면 다시 로그인 화면을 표시합니다.

## 결과

라우터와 신규 의존성을 추가하지 않습니다. 현재 URL은 유지하며 메뉴·권한 기반 화면 진입과 보호된 API에 대한 토큰 전달·만료 처리는 후속 작업입니다. 로그인 유지는 별도 요구가 정해지면 재검토합니다. 이 화면 전환은 서버 권한 판정을 대신하지 않습니다.
