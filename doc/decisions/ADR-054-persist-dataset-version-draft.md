# ADR-054: 데이터셋 버전 편집본 저장

- 상태: 채택
- 날짜: 2026-11-25
- 관련 결정: [ADR-053](ADR-053-edit-from-dataset-version.md)

## 맥락

현재 편집 파일은 DB에 저장되지만 화면 이탈 후 버전 목록에서 다시 열 항목과 변경 설명이 필요합니다.

## 대안

- 개별 편집 스냅샷은 여러 작업을 동시에 저장할 수 있으며 편집 파일 저장 구조의 변경이 필요합니다.
- 기존 공유 편집본을 재사용하면 파일 저장 경로를 유지하면서 작업을 이어갈 수 있습니다.

## 결정

데이터셋마다 공유 편집본 한 건의 기준 버전과 변경 설명을 기록합니다. 버전 목록에는 ‘편집 중’과 ‘영구’를 표시합니다. 영구 버전 확정 트랜잭션에서 편집본 표시를 제거합니다.

## 결과

다른 기준 버전에서 편집을 시작하면 확인 후 공유 편집 상태를 교체합니다. 중간 저장에는 영구 버전 번호를 사용하지 않습니다. [API 계약](../api/api.md#데이터셋-버전-편집본)
