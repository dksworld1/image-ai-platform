# ADR-044: 데이터 파일은 이미지 포함 원본 바이너리로 저장

- 상태: 채택
- 날짜: 2026-11-13
- 대체/관련 기록: ADR-043의 데이터 파일 이미지 제외 방침 대체

## 맥락

사용자는 데이터 파일 탭을 파일 형식에 관계없는 바이너리 업로드 모드로 정의했습니다. 이미지도 허용하며 썸네일을 관리하지 않습니다.

## 대안

- 이미지 형식 판별·거부 유지: 데이터 파일 탭의 바이너리 업로드 목적에 맞지 않습니다.
- 파일 내용을 해석하지 않고 원본 저장: 이미지 포함 모든 형식을 동일하게 관리합니다.

## 결정

데이터 파일 업로드의 이미지 확장자·시그니처·ImageIO 판별과 거부를 제거합니다. 파일 종류와 무관하게 application/octet-stream으로 원본 바이트를 저장·다운로드합니다. 썸네일 생성·저장·목록 표시와 원본 이미지 미리보기는 제공하지 않습니다.

## 결과

기존 파일명·크기·설명 검증, 권한, 데이터셋 내 중복·교체·버전·이력 정책은 유지합니다. 같은 이미지를 이미지 탭과 데이터 파일 탭에 각각 등록하면 서로 독립된 항목입니다. DB 구조와 설정은 변경하지 않습니다. 상세는 [API](../api/api.md#데이터-파일-api--2026-11-13)를 따릅니다.
