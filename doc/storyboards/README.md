# 화면 스토리보드

기능별 화면 구성과 사용자 흐름을 이미지와 설명으로 보관합니다. 스토리보드는 설계 초안이며 실제 구현 상태와 구분합니다.

## 목록

| 기능 | 최신 버전 | 상태 | 화면 흐름 |
|---|---|---|---|
| [데이터셋 관리](dataset-management/README.md) | v2 | 생성 페이지·메뉴 방식 확정, 세부 설계 초안 | 데이터셋 메뉴 → 생성 페이지 → 상세 → 수정·삭제 모달 |

## 폐기 이력

- [화면·메뉴 모듈](../archive/ui/README.md): 과거 화면 관리 스토리보드와 관련 API·테이블 정의

## 보관 방식

- 기능별 폴더에 `README.md`와 스토리보드 이미지를 함께 둡니다.
- 편집용 스토리보드는 버전별 PPTX로 함께 보관할 수 있습니다. PDF는 확정본 배포가 필요할 때 생성합니다.
- 기능 문서에는 이미지, 화면 흐름, 설계 상태와 관련 문서 링크를 기록합니다.
- 이미지는 `<기능명>-v1.png`, `<기능명>-v2.png`처럼 버전을 붙이고 이전 버전도 보관합니다.
